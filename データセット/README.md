# 自分の問題を入れる

**`your_data/inbox/` に入れてください。**それだけで、画面の「問題セット」に
`your_data（あなたのデータ）` として出てきます。**設定ファイルをさわる必要はありません。**

```
データセット/                      ← いまここ
  chest_demo/                    サンプル（3問・動作確認用）
  set2/                          サンプル
  your_data/                     ★あなたの問題を入れる場所
    inbox/                         ← ここに入れます
      answers.csv                  正解（q_id,answer）。複数正解は "a,d" のようにカンマ区切り
      questions/
        <問題ID>.yaml              問題文と選択肢
        images/
          <問題ID>_img<NN>.jpg     画像（無い問題があっても構いません）
    results/                       解いた結果が自動で書かれます（自分で作る必要はありません）
```

問題のまとまりを複数使い分けたいときは、`your_data` と同じ形のフォルダを増やしてください。
`chest_demo` を丸ごとコピーして名前を変え、中身を入れ替えるのが早道です。
**フォルダ名は半角英数字**にしてください（画面の「問題セット」に出る名前になります）。

## 画像の名前の付け方

`<問題ID>_img<番号2桁>.jpg`（または .png）で並べます。
**同じ問題IDの画像ファイル数が、その問題の画像枚数**になります。

| 問題 | 画像ファイル | 枚数 |
|---|---|---|
| s001 | `s001_img01.jpg` | 1 |
| s002 | `s002_img01.jpg`, `s002_img02.jpg` | 2 |
| s003 | `s003_img01.jpg`, `s003_img02.jpg`, `s003_img03.jpg` | 3 |

この規則からファイル数を数えて、「画像1枚の問題」「2枚以上の問題」で成績を分けて比べられます。
**枚数を手で入力する必要はありません。**

## answers.csv

```
q_id,answer
s001,a
s002,b
s003,a
```

## Excel（CSV）から作る

1問ずつ YAML を書くのが面倒なら、**表計算ソフトで一覧を作って取り込めます**。
「問題の管理」タブの「問題を取り込む（Excel / CSV から）」で、記入見本をダウンロードして使ってください。

| q_id | question | answer | 画像1 | 説明1 | 画像2 | 説明2 |
|---|---|---|---|---|---|---|
| s101 | 本文（セル内で改行可） | a | s101_img01.jpg | 1枚目の説明 | | |
| s102 | 本文 | b | s102_img01.jpg | 正面 | s102_img02.jpg | 側面 |

- **画像の列は省略できます。** `<問題ID>_img01.jpg` のように名前を付けて `questions/images/` に
  置けば、枚数は自動で認識されます。**説明文を付けたいときだけ**列を使ってください
- 画像が増えたぶんだけ列を足し、**使わない欄は空のままで構いません**
- Excel が保存する Shift-JIS でもそのまま読めます
- 取り込むと YAML ファイルが作られます。**以後の編集は YAML 側で**行ってください
  （同じ問題IDのファイルが既にある場合、既定では上書きしません）

## PDF から作るなら

手で書き写すのは現実的ではありません。**AI に変換させる**のが早道です。
PDF の該当ページと、次のような指示を AI に渡してください。

```
このページの試験問題を、次の形式の YAML にしてください。1問につき1つのブロックで。

q_id: <半角英数字の問題ID>
question: |-
  <設問文>

  a <選択肢>
  b <選択肢>
  c <選択肢>
  d <選択肢>
  e <選択肢>
images:
  - file: images/<問題ID>_img01.jpg
    caption: "<図の説明。本文に『造影T1強調像を示す』等とあれば、それを写す>"

守ること:
- 本文は必ず `|-` を使い、次の行から半角スペース2つで字下げする
- 字下げに Tab や全角スペースを使わない
- 画像が無い問題では images: の行ごと省く
- 原文の表記を変えない（略語・単位・記号もそのまま）
```

画像そのものは PDF から取り出して `questions/images/` に置き、`<問題ID>_img01.jpg` の形で
名前を付けてください。

## 問題文（<問題ID>.yaml）

同梱の `chest_demo/inbox/questions/s001.yaml` をそのまま真似てください。
問題文が無くても成績の集計はできますが、**画面で問題を確認したいなら入れてください**。

## 解かせる

「まとめて実行」タブで問題セットと構成を選び、「この構成で実行する」を押します。
結果は `results/trials.jsonl` に書かれ、「成績一覧」に出ます。

## trials.jsonl の中身（自分で用意したい人向け）

外部で解かせた結果をここに置くこともできます。1行が1つの JSON で、最低限これだけあれば統計が回ります。

```json
{"config_id": "model_A", "q_id": "s001", "pred": ["a"], "gold": ["a"], "correct": true, "latency_sec": 12.3}
```

| キー | 意味 |
|---|---|
| `config_id` | 構成の名前（どの解かせ方で得た結果か） |
| `q_id` | 問題ID |
| `pred` | AI の解答 ／ `gold` 正解 |
| `correct` | 正誤（true/false） |
| `latency_sec` | 1問にかかった秒数 |
| `run_id` | いつの実行か（省略可。**入れておくと実行ごとに分けて比較できます**） |

## 同梱の画像について

同梱のサンプル画像は**自作の幾何図形**です。実在の画像ではないので、AI が不正解でも正常です。
動作確認と、ファイルの並べ方の見本としてお使いください。
